TinyJoinDatabase

The TinyJoinDatabase type is the Drizzle database the drizzle function returns: Drizzle's PostgreSQL database with the TinyJoin Client it queries as its $client.

(
  PgRemoteDatabase<TSchema> &
  {$client: Client}
)
TypeDescription
$clientClient

Drizzle's raw db.execute resolves to the rows its statement returns, as objects.
