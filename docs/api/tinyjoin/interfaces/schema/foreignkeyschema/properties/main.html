Properties

columns

The columns property contains the referencing columns, in key order. Read more.

name

The name property contains the foreign key's name. Read more.

onDelete

The onDelete property says what deleting a referenced row does to the rows that reference it. Read more.

onUpdate

The onUpdate property says what changing a referenced row's referenced values does to the rows that reference it. Read more.

referencedColumns

The referencedColumns property contains the referenced table's columns, by position in columns: its primary key, or a unique index's columns. Read more.

references

The references property names the table the key references, which may be the table's own. Read more.
