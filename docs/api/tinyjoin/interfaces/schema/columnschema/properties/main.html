Properties

default

The default property contains the column's literal DEFAULT value, and is absent when the column declares none. A column declared DEFAULT NULL has a default of null. Read more.

name

The name property contains the column's name, as the table declares it. Read more.

nullable

The nullable property is false when the column is declared NOT NULL or is part of the primary key. Read more.

type

The type property contains the column's runtime ColumnType. Read more.
