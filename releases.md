<p>This is a reverse chronological summary of TinyGres releases and their public compatibility boundaries.</p><h2 id="v0-0-5">v0.0.5</h2><p>This release establishes TinyGres as a standalone, SQL-first browser database package.</p><ul><li><a href="https://tinygres.org/api/tinygres/functions/lifecycle/create/"><code>create</code></a>() opens the packaged dedicated Worker and WebAssembly engine with no application Worker boilerplate.</li><li>Memory and persistent OPFS databases use one bounded page-native engine.</li><li>The JavaScript client provides parameterized queries, atomic scripts, callback transactions, reusable prepared statements, and table-level change subscriptions.</li><li>Typed tables support primary keys, maintained secondary and unique indexes, bounded schema additions, aggregates, and left-deep inner and left joins.</li><li><a href="https://tinygres.org/api/tinygres/interfaces/query-results/results/"><code>Results</code></a> use a familiar <code>rows</code>, <code>fields</code>, <code>affectedRows</code>, <code>command</code>, and <code>rowCount</code> shape, with TinyGres revision and changed-table metadata.</li><li>The published package includes its runtime, Worker, WASM, declarations, compatibility guide, README, release notes, and agent guidance.</li></ul><p>TinyGres remains experimental and deliberately smaller than PostgreSQL. This release does not include a PostgreSQL server or wire protocol, hosted service, remote replication, or offline-write synchronization.</p>
