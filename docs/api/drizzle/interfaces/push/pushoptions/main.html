PushOptions

The PushOptions interface configures the push function.

drop

The drop property, when true, drops each table, and each column of a table the schema keeps, that the schema leaves out, with their data. Otherwise they stay as they are. Read more.

renames

The renames property maps the new name of each renamed table, as table, or column, as table.column, to the name it had, so that push renames it, keeping its data, rather than creating it empty. A rename that has already happened changes nothing. Read more.

version

The version property gives the schema a version, zero unless it is given, which the database records. A schema whose version is lower than the database's is refused with SCHEMA_OUTDATED, so that a tab running an older copy of the application cannot undo a newer one's changes. Read more.
