ColumnType

ForeignKeyAction

The ForeignKeyAction type names what deleting or updating a referenced row does to the rows that reference it: no action and restrict refuse it, cascade deletes or updates them too, and set null and set default change their referencing columns to NULL or to the columns' defaults. Read more.
