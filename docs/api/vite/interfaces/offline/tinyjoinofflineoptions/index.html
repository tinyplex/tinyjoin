TinyjoinOfflineOptions

The TinyjoinOfflineOptions interface configures production offline caching.

Since

v0.1.0

mode

The mode property selects automatic service-worker registration or integration with an existing service worker. The default is service-worker. Read more.

navigationFallback

The navigationFallback property names the emitted HTML file served for otherwise unmatched navigation requests within the application scope. It defaults to index.html; use false to disable SPA navigation fallback. Read more.
